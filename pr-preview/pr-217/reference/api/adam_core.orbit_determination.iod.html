adam_core.orbit_determination.iod.run_iod(observations: OrbitDeterminationObservations, propagator: Propagator, *, min_obs: int = 6, min_arc_length: float = 1.0, contamination_percentage: float = 20.0, rchi2_threshold: float = 200.0, observation_selection_method: Literal['combinations', 'first+middle+last', 'thirds', 'spans'] = 'spans', light_time: bool = True, max_triplets: int | None = None, velocity_method: Literal['gauss', 'gibbs', 'herrick+gibbs', 'auto'] = 'gibbs', span_settings: dict | None = None, acceptance: Literal['corrected', 'prefit'] = 'corrected', correction_settings: dict | None = None, fit_settings: dict | None = None, observatory_bias_model: ObservationUncertaintyModel | None = None) → Tuple[FittedOrbits, FittedOrbitMembers, IodReport][source]¶

The IOD stage: Gauss preliminary orbits on observation triplets, scored on propagator and accepted in one of two ways. acceptance= "corrected" (default) treats each Gauss orbit as a seed for differential corrections: in increasing prefit reduced chi2, up to max_corrections candidates are corrected on the observations their triplet spans, then on spans grown fourfold (jumping apparition gaps) up to the whole arc, every stage within rchi2_threshold; the converged candidate with the lowest whole-arc reduced chi2 is accepted and its orbit is that corrected, unrejected fit. "prefit" is the legacy gate: the first raw Gauss orbit within rchi2_threshold on every observation (after the outlier trial).

This is the native stage behind iod, NativeOrbitFitter.initial_fit and the IOD half of run_od. propagator is explicit: it is the backend that scores candidates and may differ from the one that later refines the orbit. A Rust-backed propagator exposing the fused run_iod work unit runs the whole search in one crossing; any other propagator runs the same Rust search through its own generate_ephemeris.

Parameters:

  • observations (OrbitDeterminationObservations) – Observations believed to belong to one object (any row order; the search sorts by epoch, station and row and reports in input order).

  • propagator (~adam_core.propagator.Propagator) – The propagator instance that scores candidates.

  • min_obs

  • min_arc_length

  • contamination_percentage

  • rchi2_threshold

:param : :param observation_selection_method: As for iod. :param light_time: As for iod. :param max_triplets: Bound on the triplets searched; None keeps the legacy budget of three

triplets per allowed outlier ("spans": its own default budget).

Parameters:

  • velocity_method ({"gauss", "gibbs", "herrick+gibbs", "auto"}) – Velocity of the Gauss candidates. "auto" uses Herrick-Gibbs when consecutive position vectors are within 5 degrees (Vallado 2013) and Gibbs otherwise; candidates record the method used.

  • span_settings (dict, optional) – Overrides of the observation_selection_method="spans" search (keys span_target_days, span_min_days, span_max_days, span_dense_window_days, span_edge_window_days, span_max_triplets); missing keys keep the Rust defaults of SpanSearchConfig.

  • acceptance ({"corrected", "prefit"}) – See above.

  • correction_settings (dict, optional) – Overrides of the corrected acceptance (keys max_corrections, max_converged, correction_growth, min_stage_obs, max_stages, stage_loss); missing keys keep the Rust CorrectionConfig defaults. stage_loss is the loss of the stages before the whole arc: "huber" (default) down-weights observations a partial orbit predicts badly and gates each stage on its robust cost; "linear" turns that off.

  • fit_settings (dict, optional) – Solver settings of the correction stages (as fit_least_squares’s; the whole-arc stage uses the linear loss, the earlier ones stage_loss; all skip covariance validation).

  • observatory_bias_model (ObservationUncertaintyModel, optional) – Applied to the observations before the search.

Returns:

  • orbit (FittedOrbits (0 or 1)) – The accepted preliminary orbit at its exact Gauss epoch.

  • members (FittedOrbitMembers (0 or N)) – Residuals and solution / outlier flags of every observation against the accepted orbit, in input order.

  • report (IodReport) – Every scored candidate, the accepted index, the search counters and the reason when no orbit was accepted.
