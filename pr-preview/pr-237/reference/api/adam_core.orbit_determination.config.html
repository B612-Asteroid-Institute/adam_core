adam_core.orbit_determination.config module¶

Complete declarative Core-owned orbit-determination configuration.

Every scientific declaration is serialized canonically and parsed, validated, and re-emitted by Rust. Python classes provide immutable typed construction; they do not implement validation or scientific defaults.
