adam_core.photometry.color_determination module¶

Canonical-filter-generic asteroid color estimation.

The public facade in this module intentionally owns no scientific computation. It marshals native ADAM tables and configuration into one fused Rust call, validates the exact returned Arrow schema, and wraps that batch as a quivr table.

class adam_core.photometry.color_determination.ColorFit(table: Table, **kwargs: int | float | str)[source]¶

Bases: Table

One per-object color-fit outcome and aligned canonical-filter products.

Rust returns this exact schema. For status == "ok", every list is non-null. filter_ids contains final active canonical filters in deterministic lexical order; absolute magnitudes, their sigmas, per-filter used counts, and the row-major magnitude covariance align with that order. The four pair lists enumerate every lhs < rhs pair and define color = H_lhs - H_rhs. A one-filter result has present empty pair lists.

List children are never Arrow null. Floating-point non-identifiability is represented by NaN. Forced phase_param_out_of_bounds retains only filter_ids and num_used_by_filter among the lists; every other non-ok status has all list fields null. Scalar fit diagnostics remain when a fit ran. no_orbit and multiple_orbits retain num_obs but have null classification counts; failures after row classification may retain counts, where num_used means rows admitted to the attempted fit. For every classified object the aggregate partition is exact:

num_obs = num_invalid + num_unsupported_filter + num_clipped + num_used

See migration/public_surface/photometry_constants.md for the complete Rust-native contract.

table: pa.Table¶
adam_core.photometry.color_determination.estimate_colors(observations: SourceCatalog, orbits: Orbits, phi_type: Literal['HG12star', 'HG', 'c1c2'], force_g_bounds: bool = True, color_term_composition: str | tuple[float, float] | None = None, strict_band_mapping: bool = False, filter_projection: Mapping[str, str] | None = None) → ColorFit[source]¶

Estimate canonical-filter absolute magnitudes and colors per object.

This is a thin facade over the public high-level adam_core::estimate_colors Rust API through one private IPC adapter. Rust owns object grouping and isolation, orbit matching and propagation, observer geometry, validity classification, canonical filter resolution, optional projection, every phase-law fit, clipping, identifiability, covariance, diagnostics, statuses/counts, and final Arrow assembly.

Parameters:

  • observations – Native SourceCatalog. Rows with null object_id are skipped; every attributable row is retained for diagnostic accounting.

  • orbits – Native Orbits. A nonempty table must use Cartesian ecliptic coordinates; frame/representation/epoch errors are call-level validation errors. Heliocentric origin is checked per matched orbit. Objects with zero or multiple matching orbits receive isolated status rows; an empty table assigns no_orbit to every object. Active non-gravitational solutions are rejected per object.

  • phi_type – "HG12star", "HG", or "c1c2".

  • force_g_bounds – If true, withhold scientific list products when a fitted slope is outside its model validity bounds: G12* in [0, 1] under "HG12star" and G in [-0.255, 1] under "HG". It has no effect with "c1c2". Fit diagnostics and filter/count lists remain available.

  • color_term_composition – Reflectance template ID or (weight_C, weight_S) mix required by filter_projection. It is invalid without an explicit projection.

  • strict_band_mapping – Disable only generic SDSS/PS1 fallback mapping. Canonical IDs and exact observatory mappings remain accepted; unresolved rows are counted as unsupported instead of aborting the batch.

  • filter_projection – Explicit canonical source-to-target mapping. Only listed sources are eligible, including identity edges; Rust converts using color_term_composition before pooling and emits target IDs. It is invalid without a composition. None (default) is native mode: every resolved canonical filter is fitted as a distinct intercept.

Returns:

One row per first-appearing non-null observation object ID. Status is one of "ok", "no_orbit", "multiple_orbits", "no_usable_photometry", "too_many_outliers", "phase_param_out_of_bounds", or "failed". no_orbit, multiple_orbits, and failures before row classification retain only error and num_obs among nullable scalar diagnostics/counts. Failures after classification retain an exact count partition, where num_used means rows admitted to the attempted fit.

Return type:

ColorFit

Raises:

ValueError – If whole-call configuration, projection/composition pairing, the nonempty orbit table’s frame/representation/epochs, native setup, IPC, or returned schema is invalid. A matching orbit with a non-heliocentric origin is instead isolated as an object-level failed row.
